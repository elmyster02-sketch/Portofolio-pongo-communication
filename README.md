# PONGO COM

Site vitrine statique en HTML/CSS, prêt pour Vercel.

## Pages
Accueil (`index.html`), À propos, Services, Réalisations, Contact.

## Déploiement
Importer ce dépôt dans Vercel, choisir **Other** comme framework, laisser la commande de build vide et utiliser `.` comme répertoire de sortie. Les fichiers sont servis statiquement.

Le formulaire de contact utilise `mailto:` et nécessite un client e-mail configuré.

La page de portfolio historique est conservée dans `portfolio-original.html`.
